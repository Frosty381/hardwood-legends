25 November 2026 · Release 1.0 — Update log launch

CYBER Update Centre

The central update log is now part of the CYBER homepage experience.

ADDEDNew features

  • A dedicated What's New page for platform and game updates.
  • A link to update logs from the main CYBER navigation and signed-in account panel.
  • A first-login release notice for this update, shown once per browser.
  • Separate sections for additions, changes, fixes and removals so future notes are clear.

CHANGEDPlatform

  • Release notes now have one central location instead of being buried in chat or commit messages.

FIXEDVerified fixes

  • Restored the complete Dust Line Open Range source from your original 579 KB upload. The GitHub copy had been truncated at about 76 KB and was missing the rest of its game code.
  • Confirmed that the restored file now contains its closing script, body and HTML tags. This is a source-integrity check, not a full browser-playtest.

REMOVEDRemoved content

  • Nothing removed in this release.

Testing note: source-code review can reveal likely defects, but it cannot prove that every game works on every device or network. A fix will only be marked verified after the affected game has been tested.

25 November 2026 · Release 1.1 — New game

Deflect – Wave Survival

A new first-person wave-survival shooter has joined the CYBER library.

ADDEDNew game

  • Added Deflect – Wave Survival to the CYBER homepage and game library.
  • Added an arena survival mode with escalating enemy waves and score streaks.
  • Added energy shields that reflect incoming bullets, plus blue and yellow shield modes.
  • Added boss encounters, a lava-beast sequence, upgrade choices and a best-score record saved in the browser.

CHANGEDPlatform

  • Updated the first-login release notice so players can be shown this new release entry.

FIXEDVerified fixes

  • No additional gameplay fixes are claimed in this release; the uploaded game source was added as supplied.

REMOVEDRemoved content

  • Nothing removed in this release.
