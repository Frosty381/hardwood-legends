25 November 2026 · Release 1.3 — Community game submissions

Submit your game to CYBER

Players can now send their own game files to CYBER for a manual quality review.

ADDEDCreator submissions

  • Added a Submit a Game button to the homepage and a dedicated upload page.
  • Accepted file formats are .html, .htm and .zip, with a 25 MB maximum upload size.
  • Added a private submissions inbox for the CYBER owner account, with secure file downloads and review status controls.
  • Added submission history so players can check whether a game is pending, approved or not accepted.
  • Added a confirmation message explaining that games are reviewed and only added if they meet CYBER's quality requirements.

CHANGEDReview process

  • Submitted games are stored privately and are not published automatically. The owner must inspect and approve a game before adding it to the public library.

SETUPOne-time database setup required

  • Run the separate game-submissions-setup.sql file in the existing Supabase SQL Editor to create the private storage bucket, submission table and access rules.
  • The owner inbox is restricted to the CYBER account associated with the owner email configured in the setup script.
  • Submissions appear in the private CYBER inbox; this version does not send an email notification.

REMOVEDRemoved content

  • Nothing removed.
25 November 2026 · Release 1.2 — CYBER community

Friends & Chat

CYBER now has a dedicated community area for finding other players and chatting after a friend request is accepted.

ADDEDFriends and messaging

  • Added a Friends & Chat page linked from the CYBER homepage and account area.
  • Added username-based player search and player profiles that do not show email addresses.
  • Added incoming and outgoing friend requests, including accept, decline and cancel actions.
  • Added private one-to-one messages for accepted friends, with live incoming-message updates.
  • Added one-to-one voice and video calling for accepted friends, with incoming-call prompts, accept/decline, mute, camera toggle and hang-up controls.
  • Added remove-friend, block and report controls, plus a basic message rate limit.

CHANGEDPrivacy and safety

  • Direct messages are restricted to accepted friends; there is no public chat room.
  • Users can block other players and report accounts. Reports are saved for the site owner to review.
  • Email addresses are not included in the player directory.

SETUPOne-time database setup required

  • The new social tables and security rules must be installed in the existing Supabase project using the repository file social-setup.sql before friend requests and chats can work.
  • The website code is deployed. Friend and chat features still need the Supabase setup script to run successfully; the updated script also installs the private call-signalling permissions.
  • The updated setup script also adds private Realtime policies for call signalling, restricted to the two accepted friends.
  • Calls use peer-to-peer WebRTC and need browser microphone/camera permission. Some restricted networks may require a TURN relay, which is not included in this first version.

REMOVEDRemoved content

  • Nothing removed.
